# Project 1 - Interview Practice Assistant

## Project Goal
This project was based on the Udacity requirement to build a reusable and shareable productivity or wellness app in PartyRock using input and output widgets.

## Overview
I built a PartyRock AI app called **Interview Practice Assistant** to help job seekers prepare for technical interviews.

The app generates:
- interview questions
- answer guidance
- improvement tips

based on the user's target role, skill topic, difficulty level, and interview goal.

## Why I Built It
I built this app to make interview preparation more structured and less overwhelming, especially for beginners.

Instead of rewriting the same prompt repeatedly in a chatbot, users can follow a repeatable workflow with fixed inputs and structured outputs.

## Inputs
- Job Role
- Skill Topic
- Difficulty Level
- Interview Goal

## Outputs
- Interview Questions
- Answer Guidance
- Improvement Tips

## Reflection
My app helps job seekers practice for technical interviews by generating interview questions, answer guidance, and improvement tips based on their target role, skill topic, difficulty level, and interview goal. I built it to make interview preparation more structured, practical, and less overwhelming for beginners.

Compared with a regular chatbot, my PartyRock app is more consistent and reusable because it has fixed inputs and structured outputs. Users do not need to rewrite the same prompt each time, and they can get a repeatable interview practice workflow more easily.
