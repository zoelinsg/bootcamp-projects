# AWS AI Practitioner Challenge

This folder contains my project work for the Udacity AWS AI Practitioner Challenge.

## Program Overview
This challenge focused on foundational AI/ML concepts, generative AI technologies, and practical use of AWS-related AI tools. It also emphasized understanding real-world AI use cases and learning how to choose suitable AI/ML solutions for different problems.

## Included Projects

### Project 1 - Interview Practice Assistant
A reusable AI app built with PartyRock to help job seekers prepare for technical interviews through structured inputs and outputs.

### Project 2 - AI Data Analysis with PartyRock
A data analysis project using PartyRock to explore a body measurements dataset, identify patterns, correlations, variation, and outliers, and generate an analysis table in CSV format.

## What I Learned
- how to structure a reusable AI workflow instead of relying on one-off chatbot prompts
- how to design input and output widgets for a task-focused AI app
- how to use AI tools to analyze structured tabular data
- how to evaluate AI-generated insights critically instead of accepting them blindly

## Tools Used
- PartyRock
- CSV datasets
- Prompt-based analysis
- GitHub for documentation
