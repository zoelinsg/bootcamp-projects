# CapZone - AI Image Transformation Practice

This project is my hands-on practice based on the learning materials from **Cloud to Crowd: Media IQ for Developers with AI**.

It extends the storefront app with Cloudinary AI features such as recoloring and generative image transformations for a more interactive product experience.

This repository version is my own study and implementation notes, not the original course starter or final code.

## What I practiced
- AI-powered image recoloring
- Generative transformations with Cloudinary
- Product media interaction in a Next.js app
- Integrating image-focused AI features into a storefront flow
