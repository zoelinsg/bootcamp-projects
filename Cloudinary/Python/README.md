# Pet Gallery - Python Media Practice

This project is my hands-on practice based on the learning materials from **Cloud to Crowd: Media IQ for Developers with Python**.

It uses Python and Flask with Cloudinary to build a simple pet gallery, focusing on image delivery, gallery rendering, and media integration from a backend-driven app.

This repository version is my own study and implementation notes, not the original course starter or final code.

## What I practiced
- Python + Flask app structure
- Cloudinary image integration
- Gallery-style media presentation
- Backend-driven media handling
