# CapZone - Next.js Media Store Practice

This project is my hands-on practice based on the learning materials from **Cloud to Crowd: Media IQ for Developers with Next.js**.

It focuses on building a small e-commerce storefront with Next.js and Cloudinary, including product pages, image delivery, overlays, and responsive media handling.

This repository version is my own study and implementation notes, not the original course starter or final code.

## What I practiced
- Next.js App Router structure
- Cloudinary image delivery and transformations
- Product listing and product detail pages
- Media-aware UI building for a storefront
