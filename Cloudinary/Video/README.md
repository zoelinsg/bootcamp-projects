# CapZone - Video Experience Practice

This project is my hands-on practice based on the learning materials from **Cloud to Crowd: Media IQ for Developers with Video**.

It explores how video can be added to a product experience using Cloudinary video delivery and player-based playback inside the storefront UI.

This repository version is my own study and implementation notes, not the original course starter or final code.

## What I practiced
- Cloudinary video delivery
- Product video modal experience
- Video player integration in a web app
- Media-focused UX for product storytelling

This project was built as part of my course-based learning workflow using the Cloud to Crowd curriculum materials.
