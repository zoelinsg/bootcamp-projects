# GitHub Skills: Getting Started with GitHub Copilot

## Skills Covered
- Understand how GitHub Copilot works, including inline suggestions, chat-based Q&A, edit mode, and agent workflows
- Practice fixing and adding page features, using Copilot to find bugs, and generating mock data
- Try using Copilot to generate commit messages, pull request summaries, and work evaluations

## Additional Notes
- GitHub Copilot is an AI coding assistant that helps with code suggestions and development tasks
- It can be used in VS Code, JetBrains IDEs, Xcode, and GitHub Codespaces
- Inline Chat and Ask Mode are useful for explanations, Edit Mode is for full-file editing, and Agent Mode can help automate tasks
- It can assist with debugging, generating test code, fixing features, extending lists, and creating sample data
- Copilot can also generate commit messages and PR descriptions when supported and permitted
