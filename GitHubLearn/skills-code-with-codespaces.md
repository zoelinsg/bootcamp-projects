# GitHub Skills: Code with Codespaces

## Skills Covered
- Learn how to create a Codespace and work with Git workflows such as editing, running, and committing code
- Customize a Docker-based development environment with images, extensions, and setup scripts
- Build a repeatable and shareable cloud development environment for team collaboration

## Additional Notes
- Codespaces is GitHub's cloud-based development environment that runs inside Docker containers
- Development environment settings are managed through the `.devcontainer/` directory
- It provides a ready-to-use setup without requiring local installation of VS Code or development tools
- It supports both browser-based and desktop VS Code editors
- You can add CLI tools, VS Code extensions, and custom initialization scripts
