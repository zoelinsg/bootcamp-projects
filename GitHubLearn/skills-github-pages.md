# GitHub Skills: GitHub Pages

## Skills Covered
- Learn the basic setup and publishing workflow for GitHub Pages
- Practice writing homepage and blog content in Markdown and applying a Jekyll theme
- Learn how to configure `_config.yml` and structure `_posts` files to build a blog

## Additional Notes
- GitHub Pages can turn a personal repository into a static website, which is useful for resumes, portfolios, and technical notes
- Website content is usually served from the `main` branch, and the homepage can be customized with `index.md`
- It uses the Jekyll engine to convert Markdown into webpages and supports themes and blog categories
- The `_config.yml` file is used to configure settings such as theme, title, and author information
- Blog posts should be placed in the `_posts` folder and follow the naming format `YYYY-MM-DD-title.md`, with YAML front matter at the top of each file
