# GitHub Skills: Communicate Using Markdown

## Skills Covered
- Understand the basic Markdown syntax, including headings, lists, code blocks, and images
- Practice writing clear and well-structured documentation on GitHub
- Create a blog post in Markdown format with headings, lists, images, and code examples, then submit it through a separate branch

## Additional Notes
- Markdown is a lightweight markup language used in GitHub Issues, Pull Requests, and `.md` files
- It can be used to structure headings, bullet points, command examples, images, and content sections
- It supports different list types, including unordered lists, ordered lists, and task lists
- Code blocks can include language tags such as `bash` or `js`
- Images can be inserted using either Markdown or HTML, with options for resizing and alignment
