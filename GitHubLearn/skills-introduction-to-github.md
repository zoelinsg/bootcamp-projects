# GitHub Skills: Introduction to GitHub

## Skills Covered
- Understand the basic concepts and workflow of GitHub, including repositories, branches, commits, and pull requests
- Create your own branch, write a Markdown file, and complete your first commit
- Practice opening and merging pull requests to become familiar with GitHub collaboration workflows
- Create an initial GitHub profile README for future job searching and portfolio presentation

## GitHub Workflow
1. **Create a branch**: Open the `main` branch dropdown, enter `my-first-branch`, and create the branch. This branch will be your workspace for the exercise.
2. **Add a file and commit**: In your branch, create a `PROFILE.md` file with the content `Welcome to my GitHub profile!`, then commit the change with a message.
3. **Open a pull request**: In the pull request page, choose `base: main` and `compare: my-first-branch`, then fill in the title and description and submit the PR.
4. **Merge the pull request**: Click `Merge pull request`, then `Confirm merge`. After merging, you can delete the branch to keep the repository clean.
5. **Create a profile README (optional)**: Create a public repository with the same name as your GitHub username and add a `README.md` file to the root directory. It will then appear on your GitHub profile page.

## Additional Notes
- GitHub is a platform for version control and collaboration built around Git, and it is widely used in open source communities and software projects
- A repository is like a project folder that stores files along with their version history
- A branch allows you to develop features or make changes safely without affecting the main line
- A commit records changes to files, and each commit should clearly describe what was changed and why
- A pull request is a core collaboration mechanism for proposing, discussing, and merging changes into the main branch
